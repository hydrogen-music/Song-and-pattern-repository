This repository contains free songs and patterns for `hydrogen`.

Feel free to add data by using a pull request or creating an issue or by sending
them to our mailing list.

## Guidelines

- Patterns and songs must be stored in the appropriate directory 
- File metadata (license, comments..) must be written in English
- If you want to publish single patterns, please export them as a h2pattern file
  (File->export pattern)
- Please set the name of the pattern and the category of the pattern (rightclick
  on pattern -> properties) before you add it to this repository (you can look
  at the [id3 musical
  genres](http://id3.org/id3v2.3.0#Appendix_A_-_Genre_List_from_ID3v1) for
  possible categories)
